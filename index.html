Backup e dados

Exportar

Salve um arquivo .json com todas as contas e fornecedores do grupo SPD. Guarde em local seguro (Drive, iCloud, pendrive). Atenção: ao contrário dos dados salvos no navegador, esse arquivo exportado NÃO fica criptografado — qualquer pessoa que o abrir vê os dados. Trate-o como um documento financeiro confidencial.

Importar

Restaura um backup exportado anteriormente. Isso substitui os dados atuais deste navegador.


Sincronização com Supabase

Guarda os dados num banco de dados na nuvem, sincronizando automaticamente entre qualquer aparelho onde você entrar com a sua conta. Protegido por login (e-mail/senha) e por regras de segurança no banco — só você, autenticado, acessa seus dados. Atenção: diferente dos dados no navegador (que ficam criptografados localmente), o que é enviado ao Supabase fica em texto normal no banco, protegido pelo login — trate as credenciais do Supabase como confidenciais.

Status: sem credenciais salvas.

Senha de acesso

O app fica protegido por senha neste navegador. Os dados são gravados de forma cifrada (criptografados) usando essa senha — ela não é enviada a nenhum servidor e não pode ser recuperada por nós se for esquecida.
